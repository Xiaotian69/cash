# Cash 路线图

Cash 从本地资产总览出发，逐步连接「记录、整理、理解」三个日常需求。
本页是方向探索，不是交付承诺；除 v1.0 外，以下功能尚未实现。

## 已发布 · v1.0

- 多类型账户及资产、负债、净资产总览。
- 基础收支记账、可选余额联动、月份统计。
- 每日快照、趋势图、资产构成及账户排行。
- 本地保存、JSON 备份与恢复、Windows 桌面安装包。

## 方向一 · 记录更顺手

探索账户转账、退款、周期账单、自定义分类、搜索筛选与账单导入。
优先考虑数据一致性，以及编辑历史记录时对余额的影响。

## 方向二 · 财务更清楚

探索月度预算、储蓄目标、现金流报表和周期复盘。
让统计口径可解释，让用户能够追溯数字来自哪里。

## 方向三 · 可选 AI 辅助

探索可配置的 AI 接口、自然语言记账、分类建议和财务摘要。
计划让用户选择服务商与数据范围，明确展示会发送的内容；AI 写入账本前应经过用户确认。
API 密钥计划通过系统安全存储管理，不放入源码、普通备份或公开仓库。

## 持续打磨

更好的可访问性、数据迁移体验、备份提醒和跨平台可用性。
欢迎在仓库 Issues 提交实际使用场景，帮助决定后续优先级。
