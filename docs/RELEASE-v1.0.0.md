# Cash 1.0 · 看清资产，记录日常

一个留在你电脑里的个人财务空间。把分散的余额、待还款和日常收支放到同一处，让财务状态更清楚。

## 本次发布

- 资产、负债与净资产总览，多类型账户管理。
- 基础记账和可选余额联动，按月份查看收支。
- 每日资产快照、趋势图、构成与排行。
- 数据本地保存，支持 JSON 备份与恢复。

## 下载与使用

下载 `Cash-1.0.0-windows-x64-setup.exe` 安装；需要 Windows x64 和 WebView2 Runtime。
安装包未进行代码签名。`SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。
首次启动为空白状态，发布包不含个人账户或账本。已有用户升级前请先导出 JSON 备份。
